  Phases:
  1. Compose stack: the API image keeps the pnpm workspace layout and runs
     migrations before starting. It does not use pnpm deploy, because that would
     copy packages/shared into node_modules, where Node won't strip types. The
     web image builds with Vite and serves through nginx, which falls back to
     index.html for client-side routes and proxies /graphql to the API. docker 
     compose up becomes the single start command. Checked with curl, plus your
     own run with the real key, which uses one Weatherstack call.
  2. End-to-end tests: a small Weatherstack stub in e2e/stub/ returns the sample
     response by default. A street containing QUOTA makes it return error 104.
     - docker-compose.e2e.yml runs the stack as its own Compose project with a
       fresh database volume. The stub replaces the real API and a placeholder
       key replaces the real one.
     - Playwright starts and stops the stack in its global setup and teardown.
     - Two specs: the full create → details → list → filter → delete journey,
       and the quota-error message.
     - Adds pnpm e2e and a separate e2e job in CI.
  3. README and AI deliverables: a README covering everything FR-14 AC2
     requires, an "AI setup" section, and a table of AI sessions per roadmap
     item. It also updates CLAUDE.md, the test plan (TR-24) and the roadmap.
